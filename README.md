# Jithendra Naidu Nara

I build **agent-facing tools and data systems** for working with real services—from routers and financial data to analytics. I care about explicit permissions, testable behavior, and making the evidence behind an answer visible.

Fort Wayne, IN · [Portfolio](https://jithendranara.dev) · [Email](mailto:jithendra.nara1@gmail.com)

## Selected work

- **[DiffProof](https://jithendranara.dev/work/diffproof/)** — A private PR-review prototype on Cloudflare Workers. It checks candidate findings against changed lines and a separate verifier before posting; the public case study shows a sanitized replay.
- **[tplinkctl](https://github.com/JithendraNara/tplinkctl)** — A [published Python CLI](https://pypi.org/project/tplink-admin-cli/) and MCP server for TP-Link router administration. Agents can inspect router state; changes require explicit confirmation.
- **[ledgerglass-open](https://github.com/JithendraNara/ledgerglass-open)** — A deploy-your-own Cloudflare Worker that makes SimpleFIN-backed finance data available to agents through MCP. The public subset includes permissioned tools, D1 migrations, and tests. [See the public project](https://ledgerglass-open.jnara01.workers.dev/).
- **[it-dashboard](https://github.com/JithendraNara/it-dashboard)** — A Flask dashboard for exploring tech-job data, with collection scripts and a DigitalOcean deployment workflow.
- **[real-time-healthcare-pipeline](https://github.com/JithendraNara/real-time-healthcare-pipeline)** — A local-first reference pipeline for synthetic health and wearable events, with Kafka ingestion, a DuckDB/dbt local path, and an AWS Glue/Iceberg target. Not a clinical deployment.
